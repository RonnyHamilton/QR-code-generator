# QR Code Generator

A simple web-based QR Code generator built with HTML, CSS, and JavaScript — create QR codes for URLs or text directly in the browser.

## 🔧 Demo

You can try it live here: https://ronnyhamilton.github.io/QR-code-generator/  

## 📄 Features

- Generate QR codes from user input (URLs, text, etc.)  
- Download or copy the generated QR code (if implemented)  
- Clean, user-friendly UI — works directly in the browser, no installation required  
- Instant generation — just enter the data and get a QR code
